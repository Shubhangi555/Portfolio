# shubhangi. — portfolio

Personal portfolio of **Shubhangi Bhosale**, React developer.
Live: https://shubhangibhosale.vercel.app

An editorial, print-inspired design: paper/ink themes, serif display type, a numbered index of work, and a few developer-flavoured details (⌘/Ctrl + K command palette, a hero written as JSX, skills as a `package.json`).

## Stack

React 17 · React Router 6 · hand-written CSS (no UI framework) · react-pdf · react-github-calendar · react-icons

## Run locally

```bash
npm install
npm start        # http://localhost:3000
npm test         # smoke test
npm run build    # production bundle in /build
```

## Editing content

All copy, links, projects and skills live in [`src/data.js`](src/data.js).
Project `live` / `code` links that are still placeholders (`#`, `YOUR_USERNAME`, `your-demo-link`) are hidden automatically.
Design tokens (colours, fonts, spacing) are at the top of [`src/style.css`](src/style.css).
